## Explicit boundaries

The installed manual is complete for its enumerated package; current monthly runtime completeness is not claimed. Runtime API availability is unknown when source evidence cannot establish it. Symbol references remain lexical candidates. Compilation does not prove gameplay or visual correctness. Screenshots require visual review. Bootstrap screenshot adapters and unverified platforms are rejected. Arbitrary scenario GML is not OS-sandboxed. MCP is available for configuration and is not automatically installed in Codex. RESOURCE_COVERAGE.md still controls full resource-family lifecycle support; unsupported generic metadata editing stays blocked.
